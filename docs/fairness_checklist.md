# FAIR Checklist

## Findable

- Software metadata are available in `codemeta.json`.
- Citation metadata are available in `CITATION.cff`.
- Outputs include a checksum manifest generated by `orbit manifest`.
- Configurations store benchmark factors, thresholds, and random seeds.

## Accessible

- Inputs and outputs use plain CSV, JSON, YAML, and PNG files.
- The README documents local installation and execution.
- Restricted resources are not redistributed; derived inputs can be regenerated from public accessions by the study team.

## Interoperable

- Required CSV schemas are provided in `data/schemas`.
- Gene identifiers are expected to be stable symbols or IDs in a single namespace per run.
- Tables use long format so they can be consumed by R, Python, command-line tools, and workflow systems.

## Reusable

- The code is licensed under MIT.
- Test coverage exercises scoring, metrics, FAIR manifests, and the demo pipeline.
- Runs are deterministic when the same seed and input files are used.
- Real-data analyses should archive accession IDs, preprocessing versions, and derived-table checksums.
